## Prepare the reference-versus-replica sheet

1. Open the [public Zomato Bengaluru restaurant listing](https://www.zomato.com/bangalore/restaurants) in a signed-out browser. Use a city-level location and avoid including personal information. Set the browser to 100% zoom.
2. Capture the listing and a public restaurant/menu view if available in your region. Record the visible URL, date, viewport dimensions and selected city for each. Keep the original source attribution beside each image.
3. Place the reference listing beside **02-discovery.png** and the public menu beside **03-menu.png**. Label the columns **Reference** and **Local replica**. Under each pair identify two comparable elements, such as the dish search and rating badge, or the price and Add control.
4. Add **06-bag.png** and a local order receipt as implementation evidence. Use a registered fictional user for the receipt. Capture **My orders**, a tasting note before/after editing, and the catalogue desk with an item expanded if your evaluator wants screenshots for every module.
5. If the reference changes or a menu is unavailable, record what was actually visible on the capture date. Use the public pages only. The local checkout requires no reference account or payment step.
